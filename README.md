# DentalCare

**DentalCare** is a modern Dental Clinic Management System designed to help clinics manage their daily activities easily and efficiently.

The system helps manage:

* Patients
* Doctors
* Appointments
* Schedules
* Dental Services
* Payments
* Clinic Settings

DentalCare provides a clean, responsive, and user-friendly dashboard for managing clinic operations in one place.

## Built With

* React
* Tailwind CSS
* Supabase

## Purpose

The goal of DentalCare is to make dental clinic management **simple, organized, and efficient**.
